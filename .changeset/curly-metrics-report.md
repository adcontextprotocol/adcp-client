Add versioned per-constituent, per-metric availability evidence to `createInlineReportingSourceExecutor`. Existing row arrays, `null`, and delivery response callbacks retain their current behavior, while evidence-bearing responses can safely represent mixed present, zero, delayed, unsupported, partial, stale, and missing metric cells. Evidence-bearing rows that claim one metric twice with contradictory values, and `availability_evidence` supplied as an accessor-backed or inherited slot, now fail closed with `INTEGRITY_FAILED` instead of silently preferring the direct value or downgrading to derived availability. The evidence slot is classified from a single bounded descriptor observation and the captured value is what gets parsed, so a slot that answers differently when it is looked at twice can no longer downgrade the response, and a cyclic or endlessly regenerated prototype chain fails closed instead of spinning. Repeated metric claims are reconciled as exact decimal quantities, so a number printed in exponent notation agrees with the equivalent plain-decimal string without rounding either claim.
