Atomically claim BigQuery warehouse batches and fence retry attempts and cursor commits during overlapping runs, so a stale overlapping run can no longer load a batch twice (#3196). A sink also refuses a retained plan that belongs to another account when it is configured for one account. Check replayed BigQuery jobs in the same project as the load destination. Re-run `REPORTING_WAREHOUSE_SINK_MIGRATION` after upgrading: it adds a `reset_generation` column.

Behavior change: reporting feed checkpoints now move forward only within a feed scope. `saveFeedConsumerCursor` ignores a cursor behind the saved one, so a host that rewound a consumer by saving an older cursor must pass the new `{ rewind: true }` option or it keeps the newer retention hold. It now resolves `true` when it wrote the checkpoint and `false` when it ignored it (it previously resolved `void`), and accepts `{ refreshUnchanged: false }` to recover an acknowledgment without renewing the retention hold. A custom store wrapper typed `Promise<void>` for `saveFeedConsumerCursor` must now return the boolean, and one that only forwards `(name, cursor)` drops the new options. New `removeFeedConsumer(name)` unregisters a consumer.

A `changesAfter` read with no cursor can throw `ReportingChangeCursorExpiredError` (`code === 'CURSOR_EXPIRED'`) when a prune commits mid-read; handle it on first reads as on saved cursors, and match on `error.code` rather than `instanceof`. New `ReportingChangeCursorExpiredError.cursor` carries the original feed position. The BigQuery sink keeps a failed first read's start position across restarts so the retention gap stays reported, matches the expiry by code (so CJS and ESM module copies behave the same), and gains `sink.reset()` to clear a sink that keeps rejecting with `CURSOR_EXPIRED`, such as a new sink that lost a startup race with pruning. Each reset starts a new job ID generation so reloaded batches are not mistaken for earlier finished jobs. `reset()` needs a store with `removeFeedConsumer`; the sink's store type keeps it optional so older wrappers still compile.
