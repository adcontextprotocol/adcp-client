'@adcp/sdk': minor

Add runtime subpaths so client-only code can stop importing `@adcp/sdk`, whose root also loads the server and testing modules (#3664, step 1). The new entry points are `@adcp/sdk/errors` (typed errors, `adcpErrorToTypedError`, `isErrorOfType`, `STANDARD_ERROR_CODES`, `getErrorRecovery`, `extractAdcpErrorInfo`, `isTerminalAdcpError`, `decideRetry`), `@adcp/sdk/version` (`ADCP_VERSION`, `LIBRARY_VERSION`, `COMPATIBLE_ADCP_VERSIONS`, `parseAdcpMajorVersion`, `resolveAdcpVersion`), `@adcp/sdk/registry` (`RegistryClient`, `sanitizeStreamText` and the rest of the registry exports), `@adcp/sdk/utils` (`canonicalize`, `canonicalJsonSha256`, media-buy status helpers, `unwrapProtocolResponse`, `parseCapabilitiesResponse`, the `*_TOOLS` lists, `brandManifestToBrandReference`), `@adcp/sdk/discovery` (`validateAdAgents`, `resolveAgentProperties`, `canonicalizeAgentUrl`, the publisher property selector helpers), `@adcp/sdk/media-buy` (`preflightUpdateMediaBuy`, the `can*` checks, `getAvailableActions`, `MediaBuyLifecycleCoordinator`), `@adcp/sdk/client/account-changes` (`streamAccountChanges`, `restoreAccountChangeCursor`, `buildAccountChangeSubscriptionRequest`) and `@adcp/sdk/client/webhook-stores` (`pgWebhookRegistrationStore`, `cleanupExpiredWebhookRegistrations`, the Redis store). `@adcp/sdk/client/core` also exports `createInMemoryAgentDiscoveryCache`, `ADCP_STATUS`, `InputRequiredError`, `DeferredSettlementOwnershipError` and `DirectContinuationRecoveryError`.

Each name is the same export as on the root, so `instanceof` agrees whichever path a caller imports, and no subpath reuses a root type name for a different shape (the root's `CreateMediaBuyRequest`, `Product` and `PackageRequest` stay the canonical aliases from `@adcp/sdk/v2/projection`). Nothing is removed from the root, and `@adcp/sdk/client` is unchanged.

`@adcp/sdk/client/core` no longer loads any module under `dist/lib/server/` (it used to load the property-list resolver and the pinned-DNS fetch from there), and `@adcp/sdk/media-buy/actions` no longer loads `server/media-buy-helpers`. The shared helpers moved out of `src/lib/server/` (`targeting-helpers` to `core/`, `pin-and-bind-fetch` to `net/`, `media-buy-helpers` to `media-buy/valid-actions`, and `errors`, `envelope-allowlist` and `pick-safe-details` to `utils/`); the old `dist/lib/server/*` files re-export them, so deep imports keep working. A new check, `npm run check:client-entry-graph` (also run as a unit test), bundles each client entry point with esbuild and fails if its module graph reaches `dist/lib/server/` or `dist/lib/testing/`.
